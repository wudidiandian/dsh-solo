# 0.1.6-rc.1 候选版

用于验证手机会话显示、历史同步及交互修复。Issue #1 保持打开，欢迎原反馈用户在原设备上复测。

## 安装

- 电脑插件：在 DeepSeek Harness 官方桌面版“插件 → 添加插件”输入 `dsh-solo-agent@0.1.6-rc.1`，选择官方 npm 源。已装旧版时先按宿主提示卸载后重装，再完全退出并重启桌面版；保留配对资料。
- Android：下载本 Release 的 `dsh-solo.apk`。这是正式应用标识、正式签名的候选 APK，可覆盖旧正式版；本地 DSH-SOLO Preview 使用不同应用标识，不能直接覆盖它。
- 请一起升级电脑插件与 App。服务器无需因本次更新升级；一般保留配对即可，如连接失败再重新扫码。
- 这是预发布：npm 使用 `next` 标签，GitHub 标为 Pre-release，不替换默认正式版入口。

## 更新内容

- 修复收到最新消息后漏取早期历史、缓存与实时消息之间的问题缺失。
- 按需读取电脑宿主的完整会话历史，支持向上分页；800 个事件只作为插件内存热窗口，不再限制可读取历史。
- 使用稳定的宿主事件编号，处理旧缓存迁移、重启冲突、迟到事件和重连补取。
- 历史加载失败可重试，缓存写入串行化，避免旧结果覆盖新结果。
- 修复阅读历史时刷新回底部的问题，保留滚动位置；优化 Markdown 解析、文本选择与分批显示。
- 默认折叠执行步骤，同步电脑发起会话的运行状态。
- 手机支持权限审批、模型的单选、多选、自定义回答与跳过；电脑或手机任一端处理后同步撤下另一端入口。
- 继续使用 App ↔ 电脑插件端到端加密。

## 请帮助验证

保留旧缓存，检查原来缺消息的会话；上下滚动长会话，查看回复流；断网恢复及重启桌面端后检查历史与新消息；验证权限审批和模型选项回答。

如仍有异常，请在 Issue #1 提供手机型号、系统版本、App/插件版本、复现步骤，以及必要的截图或录屏。请勿公开完整配对码、令牌或敏感聊天内容。
