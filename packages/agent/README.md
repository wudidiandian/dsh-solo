# DSH-SOLO

用手机远程使用电脑上的 DeepSeek Harness：查看会话、发送任务、传递附件和响应审批。

**官方安装包已内置官方云转发服务配置。普通用户无需部署服务器或填写域名，安装插件与 App 后扫码配对即可。**

## 安装

正式版在 DeepSeek Harness 桌面版的 **插件 → 添加插件** 中输入 `dsh-solo-agent` 即可安装；不指定版本时使用 npm 的 `latest` 标签。固定本版可输入 `dsh-solo-agent@0.1.4`。安装源选择官方 npm 源，镜像可能同步延迟。已有本地安装的同名插件时先卸载，再按 npm 包名安装；保留配对数据并完全退出、重启桌面版。

本地安装时，将官方 `.tgz` 解压，进入 **插件 → 添加插件**，输入包含 `package.json` 的 `package` 文件夹绝对路径，例如 `D:/DSH-SOLO/plugin/package`，点击安装并立即启用。不要只选择其中的 JavaScript 文件；安装后请保留该目录。已有同名插件时先卸载再安装，用户主目录中的 `.dsh-solo` 配对数据通常可保留。

安装完成后按宿主提示刷新或重启，在桌面版左侧点击 **手机配对**，用 DSH-SOLO App 扫码配对。插件详情页也提供“手机配对”按钮。新版在该页面内直接显示二维码，可查看或重置令牌。同机用户可选择“在浏览器打开（备用）”；远程浏览器通过宿主连接获取二维码，不访问浏览器所在设备的回环地址。

## 配置

官方构建使用维护者在打包时提供的默认服务地址；源码示例默认连接本机。自建时可以在宿主的配置补丁中覆盖该插件行：

```yaml
- id: dsh-solo-agent
  config:
    relayUrl: 'wss://relay.example.com/ws'
    workspaceRoots:
      - 'D:/projects/my-workspace'
```

`workspaceRoots` 指定允许访问的电脑目录；未配置时不开放文件目录访问。可选的 `stateDir` 指定配对令牌和会话缓存目录；默认使用第一个工作区下的 `.dsh-solo`，没有工作区时使用用户主目录下的 `.dsh-solo`。配对页含访问凭证，请勿公开二维码。

当前兼容范围为 `>=0.2.1-rc.5 <0.3.0`，实际桌面版验证结果见仓库内安装验证记录。系统通知、iOS 等计划不代表当前版本已经支持。

## 项目选择（0.1.2）

配套 App 的 **＋ → 选择项目** 列出桌面版已注册且目录可用的工作区。选中后发送第一条消息，插件在所选项目目录中创建会话并加入桌面工作区。已有会话不移动。项目列表只返回名称和标识，不扫描项目文件，也不需要设置 `workspaceRoots`；该配置仍用于旧文件接口的目录限制。App 和插件均需使用 `0.1.2` 或更新版本，中转服务器无需升级。


## 手机新建会话的工具修复（插件 0.1.3）

新建会话在发布前加载桌面端当前默认的 Agent 预设，并记录预设标识；工具及提示配置由宿主预设提供。预设加载失败时会返回错误，不再创建仅有基础工具的会话。这次只需更新电脑插件，App `0.1.2` 和服务器可继续使用。

更新后完全退出并重启桌面版，再从手机选择项目并新建会话测试。旧版手机创建且已开始对话的会话不会自动补装预设，请保留原记录并另建新会话；不会修改这些旧会话的历史或预设。


## 内嵌配对（0.1.4-beta.2）

桌面与浏览器客户端通过 Connection 的所有者专用 `/api/dsh-solo-pairing/*` 接口读取二维码、主动查看和重置令牌。响应不缓存；切换宿主、断开连接或离开面板后清除页面中的配对信息。令牌默认遮盖，重置需确认并重新生成二维码。本机 HTTP 网页仍作为备用，不放宽凭证接口的跨域权限。
